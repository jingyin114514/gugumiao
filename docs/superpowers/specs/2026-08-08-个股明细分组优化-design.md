# 个股明细分组优化 · 设计文档

日期：2026-08-08
项目：灯号监控面板（咕咕猫）
状态：已获用户确认（2026-08-08）

## 1. 背景与目标

面板的"个股明细"区域按一只股票一张卡片平铺展示。自选股数量增多后（超过 10 只），页面过长、难以翻阅。

目标：将个股明细改为**按股票名称拼音首字母分组**（A-Z，非中文开头归"#"），配合**字母索引条 + 手风琴展开/收起 + 搜索框**，让股票再多也能快速定位。交互精致度参考 detail.design 的微交互标准。

## 2. 范围

### 包含

- "个股明细"区域改造：搜索框、字母索引条、分组手风琴、空状态
- 后端序列化增加每只股票的拼音首字母字段（`initial`）
- 引入 `pypinyin` 依赖（仅面板使用）
- 完成后提交 git 备份

### 不包含（保持现状）

- 灯号总览矩阵（总览对比用途，不折叠）
- 今日行情、自选股管理
- CLI 终端报告、Markdown 报告、CSV 历史记录
- 数据抓取与灯号计算逻辑

## 3. 界面设计

自上而下结构：

1. **搜索框**：占位符"搜索名称或代码"，输入即时过滤（防抖 150ms）
2. **字母索引条**：A-Z + "#"，点击平滑滚动到对应分组；滚动时当前分组字母高亮
3. **分组手风琴**：每组一个组头（大字字母 + 股票数量 + 展开箭头）+ 组内现有详情卡片

组头元素：

- 左侧：字母（大号、粗体）
- 中部：该组股票数量（次要文字）
- 右侧：展开箭头（展开时旋转 90°）

默认状态：全部收起，只显示组头。

### 卡片内容不变

组内卡片保留现有字段：估值（PE/PB 分位）、主力资金（1/5/20 日）、机构持仓、52 周位置、最新财报、我的仓位、备注与数据提示。

## 4. 搜索行为

- 支持三种匹配方式：中文名称（如"英维克"）、股票代码（如"002837"）、拼音首字母组合（如"ywk"）
- 搜索时：自动展开含匹配结果的组、隐藏无匹配的组；匹配文字高亮
- 无结果：显示空状态"没有匹配的股票"
- 清空搜索：恢复默认全部收起状态

## 5. 交互细节（detail.design 风格）

- 展开/收起动画：250ms 缓动（`grid-template-rows` 或高度过渡）
- 箭头跟随展开状态旋转
- 组头悬停：背景微变、箭头轻微位移
- 索引条滚动高亮：监听滚动位置，当前所在组字母高亮
- 尊重系统"减弱动态效果"（`prefers-reduced-motion` 时关闭动画）

## 6. 技术方案

### 后端

- 在 `requirements.txt` 增加 `pypinyin`
- 安装到项目 `.venv`
- 序列化股票数据时（`models.stock_to_dict` 或面板侧），用 `pypinyin` 将名称转为拼音首字母：
  - 取名称每个汉字拼音首字母的第一个字符（如"英维克"→"Y"）
  - 名称含非汉字字符（数字/英文/空）→ 归"#"
  - 多音字按 `pypinyin` 默认读音（如"中"→Z）
- 面板 `/api/status` 返回的每只股票增加 `initial` 字段

### 前端（dashboard.py 内嵌页面）

- CSS：索引条（sticky）、组头、手风琴动画、空状态、高亮样式
- JS：分组渲染、索引滚动跳转与高亮、搜索过滤（防抖）、展开/收起状态管理
- 不改动其他接口与区块

## 7. 兼容性与回退

- 名称缺失或非中文 → "#" 组，不报错
- 搜索无结果 → 空状态提示，不白屏
- `pypinyin` 安装失败 → 面板需回退为按首字符 ASCII 分组（代码优先），并在数据提示中说明
- 面板其他区域与 CLI/Markdown/CSV 输出不受影响
