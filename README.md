# 灯号框架 · 自选股监控工具

个人投资者的每日自选股监控工具：自动抓取行情、主力资金、估值分位、机构持仓与财报数据，按六维灯号框架输出建仓判断，全程本地运行。

## 打开方式（推荐：可视化面板）

双击 **`启动面板.bat`**：

1. 自动启动本地服务并打开浏览器，显示可视化监控面板
2. 面板首次打开会自动联网抓取数据（约 1~2 分钟）
3. 之后每次想更新，点右上角"立即刷新"即可
4. 关闭弹出的黑色小窗口 = 关闭面板

面板长这样：

```text
┌──────────────────────────────────────────────────────┐
│  ●●○ 灯号监控 自选股面板        [查看报告] [立即刷新] │
│  更新于 2026-08-05 19:49 · 数据源 同花顺/腾讯 · 共2只 │
│  [监控股票 2] [可建仓 0] [需要关注 0] [数据提示 2]    │
│  灯号总览：英维克 🟢🟡🟡🟡🟢🟡 飞荣达 🟢🟢🟡🔴🟡🟡 │
│  个股明细：估值/主力/机构/52周位置/盈亏 卡片        │
└──────────────────────────────────────────────────────┘
```

### 在面板里添加/删除自选股

打开面板后滚动到最底部"自选股管理"：

- **添加**：输入股票代码（6 位数字，如 `600519`）→ 可选填名称/成本价/目标仓位 → 点"＋ 添加"，自动刷新数据
- **删除**：在列表里点股票后面的 ✕
- 名称留空会自动从行情识别；成本价和仓位留空则盈亏/仓位显示 `--`

添加后第一次抓取该股票需要等一次完整刷新（约 1~2 分钟）。
新添加的股票"产业逻辑"灯默认黄灯，如需手动标注，打开 `config.json` 把该股票的 `industry_light` 改成 `green` / `yellow` / `red` 即可。

## 命令行版（可选）

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
python main.py --init        # 生成默认 config.json（首次）
python main.py               # 运行一次监控
```

Windows 上也可以直接双击 `run.bat` 跑命令行版。

## 每次运行得到什么

- 终端报告：六维灯号、估值分位、主力资金、机构持仓、52 周位置、成本盈亏、建仓清单、关注清单
- `data/reports/report_YYYYMMDD_HHMM.md`：Markdown 报告（含灯号矩阵与个股明细）
- `data/history.csv`：逐股追加历史快照，用于回测灯号有效性
- 状态变化提醒：某只股票从"不可建仓"变为"可建仓"时，界面高亮 🔥 提示
- 本地面板：`启动面板.bat` 打开浏览器可视化界面，一键刷新、查看报告

## 配置（config.json）

所有阈值和股票池都可配置，核心字段：

| 配置项 | 说明 |
|---|---|
`watchlist` | 代码、名称、成本价、目标仓位、产业逻辑灯、边际备注 |
`market_cap_tiers` | 市值分档与主力资金阈值（万元）：小盘 3000 / 中盘 5000 / 大盘 1 亿 |
`capital.green_any_inflow` | 设为 `true` 时，5 日主力净流入 > 0 即亮绿灯（默认按阈值） |
`valuation` | PE/PB 分位绿灯 <50%、红灯 >80%、PE 极高阈值、最少样本数 |
`chips` | 机构家数/比例变化的正负阈值 |
`margin_keywords` | 边际变化关键词自动亮灯（含"解禁/减持/暴雷"等词自动红灯） |
`build` | 建仓条件：绿灯 ≥ 4 且红灯 = 0 |

### watchlist 示例

```json
{
  "code": "002837",
  "name": "英维克",
  "cost": 52.0,
  "target_weight": 8.0,
  "industry_light": "green",
  "industry_note": "AI 算力液冷散热，产业上行周期",
  "margin_note": "液冷订单放量；注意中报后限售解禁窗口"
}
```

- `industry_light`：产业逻辑是主观判断，直接填 `green` / `yellow` / `red`
- `margin_note`：填利好/利空关键词会自动亮灯；也可用 `margin_light` 手动覆盖
- 成本价与目标仓位不会自动更新，记得按实际持仓修改

## 数据源与口径

数据源按可用性自动降级，全部来自 akshare（yfinance 仅作最后兜底）：

| 数据 | 首选 | 备选 |
|---|---|---|
| 实时行情 | 东财实时 | 腾讯实时 → 新浪实时 → 日线收盘价 |
| 52 周区间 | 东财日线 | 新浪日线 → 腾讯日线 |
| PE/PB 与 3 年分位 | 东财估值分析 | 百度股市通 |
| 主力资金 | 东财个股资金流 | 同花顺资金流排行 |
| 机构持仓 | 新浪机构持股明细（十大流通股东口径） | — |
| 财报 | 东财财务主要指标 | 东财业绩报表 |

口径说明：

- 主力资金为"大单 + 超大单"口径；5 日/20 日为交易日累计（东财按日线求和，同花顺按其排行周期）
- 估值分位：当前 PE(TTM)/PB 在近 3 年历史中的分位（≤ 当前值的交易日占比），样本 < 60 天标黄
- 机构持仓为十大流通股东中的机构口径（基金/社保/保险/QFII 等），家数=机构股东数，比例=合计占流通股
- 单条数据缺失不会中断运行，对应灯降级为黄灯并在报告中提示

## 灯号规则

| 维度 | 🟢 | 🟡 | 🔴 |
|---|---|---|---|
| 产业逻辑 | 手动配置 | 手动配置 | 手动配置 |
| 基本面 | 营收利润双增、毛利率稳定 | 增收不增利 / 增速放缓 | 持续亏损 / 营收下滑 |
| 估值 | PE/PB 分位均 < 50% | 一个高一个合理 | 双高 > 80% 或 PE 极高 |
| 长期筹码 | 机构增持 | 机构持仓持平 | 机构大幅减仓 |
| 短期主力 | 5 日净流入 > 阈值 | 阈值内 | 5 日净流出 > 阈值 |
| 边际变化 | 催化剂关键词 | 不明确 | 利空关键词 |

建仓条件：**绿灯 ≥ 4 且无红灯**。红灯 ≥ 2 进入"需要关注"清单。

## 命令行参数

```text
python main.py --codes 002837,300602   # 只看指定股票
python main.py --no-report             # 不生成 Markdown
python main.py --no-history            # 不写历史 CSV
python main.py --color                 # 强制终端颜色
python main.py --max-workers 2         # 限制并发，降低被限流概率
python main.py --init                  # 重建默认配置模板
```

## 说明

- 本工具只读公开数据、只写本地文件，不上传任何内容
- 数据偶尔缺失是常态，界面会明确标注，不影响整体运行
- 生成内容仅供个人研究参考，不构成投资建议
